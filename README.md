# Pixel Platformer 🎮

Простая пиксельная платформенная игра на Java + Swing.

## Структура
src/
├── Game.java # Точка входа, окно
├── GamePanel.java # Игровой цикл, отрисовка
├── Player.java # Игрок (движение, прыжки, гравитация)
├── Platform.java # Платформы
├── Coin.java # Монетки
└── InputHandler.java # Обработка клавиш

resources/
└── sprites/
└── player_sprite.png # Спрайт игрока (опционально)


## Управление

| Клавиша      | Действие |
|--------------|----------|
| ← / A        | Движение влево |
| → / D        | Движение вправо |
| Пробел / W   | Прыжок |

## Запуск
javac -d out src/.java
cp -r resources/ out/
java -cp out Game

## Принципы

Код следует **SOLID** (особенно **S** — единственная ответственность):

| Класс | Что делает |
|-------|------------|
| `Game` | Окно и запуск |
| `GamePanel` | Цикл, отрисовка, связь компонентов |
| `Player` | Только логика игрока |
| `Platform` | Только платформа |
| `Coin` | Только монетка |
| `InputHandler` | Только клавиши |
